## 3. 坑位清单（每个都真实踩过，务必先读）

1. **生产机远程 shell 是 csh**：ssh 一律 `ssh root@host 'sh -s' <<'EOF' … EOF` heredoc；直接传命令串会报 "Ambiguous output redirect"。
2. **manifest 内嵌脚本（+POST_INSTALL/+PRE_DEINSTALL/+POST_DEINSTALL）禁止反斜杠续行**：pkg 的 UCL 处理会破坏续行 → 运行时语法错误（源码 sh -n 却通过）。也**禁止 `date +%Y…` 的 % 转义**（偶发被吞）。长列表写单行。
3. **pkg 格式**：主规则集里 +MANIFEST 必须是裸名（build.sh 的 GNU tar transform 已修为 `s,^\([^+]\),/\1,`，BSD 分支同理已修）；改了别改回去。
4. **pkg add -f/升级会覆盖 config.yaml 和 sub/env**（今天实测订阅被打回 bing.com），且旧进程不死净会 cache.db bbolt 锁竞态（新实例假死）。F4 就是修这个，实施前重装测试需手动恢复订阅（printf 写 env → `configctl mihomo sub-update`）。
5. **hev-socks5-tunnel**：配置是**位置参数**（`hev-socks5-tunnel /path.yml`），没有 -c；需要 `kldload if_tun`（生产已加载，新 VM 要手动）；pidfile 不可信，stop 用 pkill 兜底；FreeBSD `daemon` 参数：`-t`=进程标题、`-p`=子进程 pid、`-P`=监督 pid、`-T`=syslog tag（deepseek 审核勘误，实施前以 daemon(8) 为准）。
6. **sub.sh 超时已改 -m 120**：17MB 订阅直连/代理各 30~60s，别再改回小值；URL 必须 https；日志脱敏到 host。
7. **atomic_config_updater 是安全底线**：任何配置写入必须走它（mihomo -t 校验失败=生产配置不动）。sub.sh 已改为"临时文件合成→校验→原子替换"，别退化回直接 cp。
8. **生产路由器上 xray 栈仍在跑**（本插件的目标就是替换它）：xray/hev 在 daemon(8) `-r` 下杀子进程 5s 自动重生；`/var/run/xray_proxy.pid` 曾有陈旧 pid 坑（已手工修正）；生产 anchor 文件 `/usr/local/etc/pf.anchors/xray-proxy`，**有一条 2026-10-17 加的 VM 旁路规则（`from 192.168.30.159 to any`，备份 .bak-20261017-demo），迁移完成、VM 退役后应删除**。
9. **VM 是 Live 模式**：重启即回出厂。今天 VM 经数小时折腾已开始劣化（mihomo controller 间歇挂起，连 v1.19.30 也偶发）——**VM 上复现不了的问题别死磕，装盘后的正式 VM 才是可信测试床**。
10. **v1.19.32 内核**：在 live VM 上 controller/DNS 挂起复现 3 次，pin 已回退 v1.19.30。`work/cache/mihomo-freebsd-amd64-compatible-v1.19.32.gz` 已下载好；升级任务=磁盘版 VM 上换 pin 重建→全量回归→通过才切换。
11. **桌面机（192.168.30.166，本机）有本地端口拦截**（443/9090 回包被吞，ip rule 有 fwmark 0x80000/table 52 的 root 级组件未查明）——本机直连面板不通时用 SSH 隧道，别误判为服务端问题。
