## 5. 技术红线与陷阱（血泪浓缩，违反即翻车）

**OPNsense 26.7 插件契约**：
- `Backend::configdRun($event, $detach, ...)` 第二参是 detach；**带参数必须 `configdpRun($event, $params[])`**（数组落 detach 位会异步执行只回 job UUID）。
- configd 动作 `%s` **只能写在 `parameters:` 模板行**；command 行的 %s 原样传给脚本 → Execute error。
- `/ui/{module}/{controller}` 按控制器文件名路由：每页必须独立 `*Controller.php`。
- `registerAnchor` 只注册引用不物化规则（PF 方案死因）；模型 `<Mask>` 正则必须带 `/` 分隔符；端口用 `IntegerField`+Min/Max（Mask 会放行 65536-99999）。
- 模型字段校验/前置检查放 `setAction` **覆盖内**（同时覆盖 setGeneral 与公开 set 两条路由）；要在落盘**前**拦截。

**本项目语义红线**：
- 控制面/数据面已解耦（1.0.8）：API 探测失败 = reconcile+告警，**不得恢复为杀进程**；数据面（socks/DNS）致命判据与 fail-open 原语义保持。
- config.yaml 的 `^secret:` 实际值才是认证真源（secret.key 存在≠生效）；所有非回环渲染路径必须过 secret 有效值门禁。
- 写 config.yaml/template 必须持 `/var/run/mihomo-sub.lock`（复用 sub_lib/secret_manager 同款协议）+ 写后 `grep -qF` 校验 + 失败回滚。
- `+POST_INSTALL` 内嵌 manifest：**禁 % 字符、禁反斜杠续行**（printf '%s' 都不行，用 base64 命令/echo）。
- 不碰：config.xml 主结构（迁移 php 片段除外）、Unbound 主配置、PF 主规则集、sub.sh 合成算法、atomic_config_updater 契约。

**shell/测试陷阱**：
- `pkill -f "模式"` 会匹配自己 shell 的命令行（同链后面出现同文本即自杀）→ `[s]sh` 字符类 + 分步。
- `$(sleep 30 & echo $!)` 造的伪持锁者 pid 秒死（ssh 进程组）→ 测锁用 `nohup sh -c 'echo $$ > pidfile; sleep N' &`。
- `sockstat -4` 漏 tcp46 双栈（统一不带 -4）；0.0.0.0 绑定 = tcp46（IPv6 同听，别加 inet 限定）。
- VM 上跑 python 会生成 `__pycache__` 混入打包（build.sh 已 exclude；verify 会拦，别把 pyc 提交进 git）。
- 工作流 actor 上下文超 13M token 后回合可卡死 10min+ → 编码任务拆包要控制单 agent 规模；卡死就主控接管。
- 模型供应商 ID 会漂（会话中也可能漂，gemini/deepseek 曾互换前缀）→ workflow 报错会列可用模型，照抄即可；子 agent 只用 gemini/deepseek，禁止降级 GLM。

## 6. 工作流模式（已验证可复用）

- **双模型并行编码**：主控定文件集不相交的两包 → Gemini（PHP/UI）+ DeepSeek（shell/基础设施）并行 → 全量测试门禁（失败路由回原编码员，≤3 轮）→ 交叉审计互审对方包 → 修复复跑 → 主控亲审 diff + VM php -l + 构建 + 部署回归。脚本样例：`.zcode/workflow-drafts/v1.0.8-api-bind-并行编码.dwf.ts`。
- facade 速记：`Node<T>` 非 Promise（数组用 `PromiseLike<T>[]`）；actor 名唯一（跨轮续话复用 agent 对象变量）；typed ask 可能"无 submit_result"结束（包 try/catch + 换名重试一次）；provider 限流运行时自动重试。
